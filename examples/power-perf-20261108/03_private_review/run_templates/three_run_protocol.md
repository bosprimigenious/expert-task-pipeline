# 3次新会话盲测协议
此为内部计划，不是本次已执行结果，也不是已核验的强制平台要求。
1. 三次保持同一公开题包、模型可见身份、档位和网络权限。新会话只给task_prompt.md与7个zip，不能给作者总包、标准答案、评分器、难点卡、目标分数或上轮回复。
2. 按实际产品提供的高推理档位设置并截图留证；没有配置就写不可确认，提示词不能强行开启模式。可使用脚本和正常工具，不限速、不等待凑时。
3. 外部记录起止；结束取正式终结/实际终止/预算截止最先者，不包含上传前准备与之后判分。若平台口径不同，保留官方原值并单列。
4. 按平台定义记录完整模型决策输出轮数；Tool Calls另列。没有原始可核验轨迹就NOT_VERIFIABLE，不从正文估计。
5. 收回全部文件和回复，按哈希封存，再判分；不得读分后修改同一次结果。3次全部保留，不挑最低一次。
6. 公布每次Score、Time、Verified Steps、环境有效性与评分待审项。官方转述逻辑S<=50且(T>2400或V>=50)；用户内部严格目标S<50且T>2400且V>=50。
7. 未决、环境故障、失败与无效运行分别记录。3/3也只是3次观察，不保证未来稳定。开发期改题后另建版本，正式留出不得参与反复调权重。
