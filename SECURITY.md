# Security

- This repository contains **no credentials, cookies or tokens**.
- Do not add browser profiles, session stores or `.env` files.
- `03_private_review/` contains the reference answer and grader. Never upload it
  to a model or a public task pack.
- The task data is synthetic. Do not present it as a real utility’s records.
- Report a privacy or credential issue by opening a private security advisory;
  do not publish the credential in an issue.
