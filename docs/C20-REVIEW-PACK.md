# C20 人工评审包

## 边界
- AI 可做独立技术评审，但不能冒充持证 DBA/IAM/SRE 签名。
- 平台要求 2 名真人评审 + 1 名仲裁；AI 评审只作为输入。

## 文件
- `C20-REVIEW-PACK/FORM-<task>.md`：0/2/5 分制，逐项证据。
- `ARBITRATION.md`：分歧与仲裁结论。
- `AUTHORIZATION-TEMPLATE.md`：公开 Trace/合成场景授权，项目方签字。

## 评分口径
- 5：结论正确、证据充分、推理完整、措施可执行。
- 2：方向正确但有重要证据缺口/风险遗漏。
- 0：核心结论错误、无证据或不安全决策。
