# 平台七列与分类

## 七列
1 任务名称；2 任务类型；3 prompt；4 输入附件；5 考点 rubric；6 作答思路；7 标准答案（文本 + 附件）。

## 分类是两套，不要混
- 行业 L1/L2：如 科技、软件与数字基础设施 → 企业软件与 SaaS / 互联网平台与数字产品 / AI 与数据技术 / 硬件、半导体、云与。
- 职业簇 L1：服务端/全栈、Web/前端、客户端、平台/基础设施、数据工程与开发、安全工程、模型自动化研究、嵌入式、芯片设计。
- 岗位 L2：基础设施工程师、数据库运维/DBA、安全平台工程师、研发效能工程师等。

## 参考答案写法
- “标准答案-文本”写结论+关键数字+边界（可读成段），不贴几十个文件。
- “标准答案-附件”放参考 CSV/JSON/MD 原文件；平台拒 zip 时逐个上传。
