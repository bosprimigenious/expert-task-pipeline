# Contributing

Good contributions improve the pipeline, not just the prose:

- schema preflight rules and tests;
- grader calibration and adversarial fixtures;
- staged artifact contracts and failure handling;
- new case studies with **honest failed runs**.

Please do not add:

- credentials or browser session data;
- real customer/employer data without written authorization;
- claims of platform acceptance without a receipt;
- a “pass” produced by editing a failed run after the fact.

For a new case, include:

- source and authorization;
- input hashes;
- prompt and public pack;
- reference answer and rubric;
- at least one real model run with preflight and score status;
- known limitations.

Run the preflight before proposing a grader change.
